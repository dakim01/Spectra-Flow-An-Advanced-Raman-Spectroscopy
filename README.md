# Spectra-Flow-An-Advanced-Raman-Spectroscopy
Advanced ML pipeline for Raman spectroscopy analysis predicting chemical concentrations (Glucose, Acetate, Magnesium Sulfate). Features: airPLS baseline correction, SNV normalization, peak detection, ensemble methods (R²: 0.98+). Includes comprehensive visualizations &amp; applicable to SERS research. Built with Python, scikit-learn, scipy.
